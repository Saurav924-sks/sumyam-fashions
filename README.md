# SUMYAM Fashions

A responsive fashion storefront homepage created with semantic HTML, CSS Grid and Flexbox, and vanilla JavaScript for a Web Technology assignment.

## Run locally

Open `index.html` directly in a browser, or open this folder in Visual Studio Code and use Live Server. There is no build step or installation required.

## What to explore

- Use the collection cards and the All pieces, Women, Men, and Essentials filters to browse products.
- Search product names and descriptions from the product section.
- Add products to the bag to see the in-page item count and demo confirmation.
- Use the menu button at a narrow viewport and submit an email in the newsletter demo.

Product prices and store details are fictional demonstration content. The bag does not place orders. The newsletter form validates input in your browser and does not send or save it. Fashion photos are local files in `assets/images/`.

## Assignment features

The CSS demonstrates backgrounds and borders, editorial typography and text treatments, keyframe animations and transitions, responsive multi-column Grid/Flexbox layouts, and interface principles such as hierarchy, focus visibility, contrast, and reduced-motion support.
